# Тестируем разные библиотеки Python

## Alembic
### Работа с миграциями локально
- изначальная инициализация Alembic
  - alembic init alembic
- автогенерация миграции  
  Здесь Alembic смотрит на текущее состояние БД, 
  и на основе разницы в БД и моделях строит скрипты наката и отката миграций
  - alembic revision --autogenerate -m "Comment to migration"
- накат миграций
  - alembic upgrade head
- откат миграций
  - alembic downgrade -1

### Порядок создания и накатки миграций для стенда
- локально, (авто)генерируем файл миграций через alembic revision ...
- при старте сервиса, запускам миграции, указывая путь к файлу с миграцией в config
  - command.upgrade(config, 'head')
